# 时刻 · 闹钟与倒计时

一款支持闹钟、倒计时和稍后提醒的计时应用，可直接在浏览器中使用，也可安装为 Windows 桌面应用。

## 打开方式

- 在线使用：<https://yao-hub.github.io/alarm-clock/>
- 本地运行：在项目目录执行 `npm run dev`，再访问 <http://127.0.0.1:8765/>。

提示音由浏览器内的 Web Audio 实时合成，不依赖任何音频文件（也可上传音频）。

## 桌面应用

桌面版使用 Tauri 封装同一套前端代码，关闭窗口后会驻留系统托盘，闹钟和倒计时继续运行。

| 命令 | 用途 |
|---|---|
| `npm ci` | 按锁文件安装 Tauri 与 Vite 工具链 |
| `npm run desktop:dev` | 启动桌面开发版 |
| `npm run desktop:build` | 构建 Windows 安装包 |

安装包输出到 `src-tauri/target/release/bundle/nsis/`。

### 构建环境

在另一台 Windows x64 电脑上构建，需要预先安装：

1. Node.js 22 或更高版本。
2. Rust stable 工具链，使用 `rustup` 安装。
3. Visual Studio 2022 Build Tools，并勾选“使用 C++ 的桌面开发”工作负载。

然后执行：

```powershell
npm ci
npm run desktop:build
```

项目已提交 `package-lock.json` 和 `Cargo.lock`，不同电脑会安装相同的依赖版本。也可以直接在 GitHub Actions 中运行 `Build Windows Desktop Installer`，从构建产物下载安装包。

## 发布桌面版本

推送 `v*` 标签后，GitHub Actions 会自动构建 Windows 安装包并发布 GitHub Release：

```powershell
git tag v0.1.6
git push origin v0.1.6
```

发布前需要同步更新 `package.json`、`src-tauri/Cargo.toml` 和 `src-tauri/tauri.conf.json` 中的版本号。手动运行 `Build Windows Desktop Installer` 时不会创建 Release，只会生成 Actions 构建产物。

## 项目结构

| 目录 | 职责 |
|---|---|
| `index.html` | 页面语义结构与组件挂载点 |
| `styles/` | 全局样式、响应式布局与组件样式 |
| `src/core/` | 状态存储、音频引擎、闹钟检测等业务能力 |
| `src/components/` | 表盘、闹钟列表、倒计时、弹窗、响铃等界面组件 |
| `src/utils/` | DOM 与时间处理工具 |
| `src/app.js` | 应用初始化与组件编排 |

## 功能

- **闹钟**：多个闹钟并存，可设时间、备注、重复（工作日 / 每天 / 周末 / 仅一次 / 任意星期组合），单个开关与编辑、删除；另有「常用模板」一键添加 12:00 开始午休、13:30 下午上班、17:30 下班三个工作日提醒。
- **倒计时**：时/分/秒输入，5 个常用预设（1 / 5 / 10 / 25 / 45 分钟），开始、暂停、重置，表盘进度环与指针同步；完成后记入「最近完成的计时」（保留 5 条，点击记录可载入时长，也可删除）。
- **设置**：顶部设置入口可配置默认提示音、音量、闹钟响铃时长和倒计时响铃时长；提示音支持经典铜铃、电子滴答、西敏报时、木琴晨曲、林间鸟鸣及多个上传 mp3 / wav。点击提示音可试听，再次点击同一项可停止。
- **响铃时长**：闹钟与倒计时可分别设置精确到秒的响铃时长；全部设为 0 时不自动停止，可随时手动停止。
- **响铃界面**：闹钟支持停止 / 5 分钟后再响，稍后提醒会在闹钟列表下方显示原定时间和倒计时，并提供“关闭”操作；关闭或删除原闹钟会同步取消待触发的稍后提醒。倒计时结束会显示本次计时时长，并支持停止 / 再来一次。
- **桌面通知**：到点弹出系统通知，点击通知可唤醒主窗口；闹钟可直接「停止」或「5 分钟后再响」，倒计时可直接「停止」或「再来一次」。
- **其他**：闹钟、设置、音量与计时记录存于 localStorage，刷新后仍在。

## 表盘读法

- **闹钟视图**：12 小时表盘，时针/分针为金色，秒针为红色细针；盘面下方是数字时间与工作日的日期。
- **倒计时视图**：一圈代表整个倒计时时长，金色指针从 12 点顺时针走过的是已过时间，外圈金色圆弧与指针同步。盘面四个数字是「走到该处时的剩余时间」，随设定时长自动换算（例如 25 分钟为 25:00 / 18:45 / 12:30 / 06:15），不是固定分钟刻度。下方大数字始终是精确剩余时间。

## 已知限制

1. 页面必须保持打开，关闭标签页后闹钟与倒计时都不会触发（纯前端网页的固有边界，没有后台常驻进程）。
2. 浏览器后台标签页会被节流，响铃可能晚几秒；桌面通知需要首次允许后才能弹出。
3. 自定义音频来自 `<input type=file>`，浏览器安全策略不允许持久化文件本身，刷新后会回到默认提示音，需重新选择。
4. 桌面通知的权限只在「第一次保存闹钟」时申请一次；忽略或拒绝后不会再弹窗，需要时可在浏览器地址栏左侧的站点设置里手动改为允许。
5. 「5 分钟后再响」是页面内的定时器，刷新页面即失效。
6. 音效为实时合成，音色偏"电子钟"，不是真实录音素材。

## 快捷键

- 空格：在倒计时视图开始 / 暂停（焦点不在输入框时）
- Esc：关闭弹窗或停止响铃
